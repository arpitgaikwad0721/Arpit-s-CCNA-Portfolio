# Arpit's CCNA Portfolio

My hands-on progress through **Jeremy's IT Lab's CCNA 200-301 course**, documented day by day.

This repository contains my Packet Tracer labs, notes, screenshots, configurations, and other practice material as I work through the course.

## Goal

The goal of this repository is to keep a practical record of my CCNA learning journey rather than just collecting notes. Each day will contain the work I completed, what I learned, and the relevant Packet Tracer files.

The course starts with basic networking concepts and is intended for learners who want to learn computer networking and/or prepare for the CCNA 200-301 exam.

## Topics Covered

As I progress through the course, this repository will cover topics such as:

- Network fundamentals
- Clients and servers
- LANs
- Switches
- Routers
- Firewalls
- Cisco IOS and device configuration
- Packet Tracer labs
- Networking concepts required for CCNA preparation

The course also includes supplementary learning through end-of-video quizzes, Anki flash cards, and Packet Tracer practice labs.
